# Finance — Omarchy bar plugin (`idanco.finance`)

A stocks pill for the Omarchy bar, backed by your Interactive Brokers account.

- **Bar pill**: portfolio day change (green/red), e.g. ` +1.14%`.
- **Popup** (click the pill): total portfolio value, unrealized P&L, portfolio
  **DTD / MTD / YTD**, the **USD/ILS, CHF/ILS, EUR/ILS** rates with day change,
  and every position with price, DTD, MTD, YTD and value.
- **Click a ticker**: historical P&L chart (1M / 6M / 1Y / 5Y) on top, an
  **AI summary** (most important news, analyst view, and a portfolio-aware tip
  — generated by the machine's default Omarchy agent, see below), and recent
  news. Clicking a headline opens it in the browser.
- Middle-click the pill to force a fresh IBKR positions fetch.
- Esc goes back from the detail view / closes the popup.

## Data sources

| Data | Source |
|------|--------|
| Positions + cost basis | **IBKR Flex Web Service** (token + query id — no gateway needed) |
| Prices + daily history | Yahoo Finance, with automatic fallback to the Nasdaq API |
| FX rates | frankfurter.dev (ECB reference rates) |
| News | Google News RSS |

The fetcher (`bin/finance-fetch`) is stdlib-only Python — nothing to install.

## Install

```bash
./install.sh
```

This copies the plugin to `~/.config/omarchy/plugins/idanco.finance/`, enables
it, and creates `~/.config/omarchy/finance/config.json` if missing. After
editing plugin source here, re-run `install.sh` to sync (the shell hot-reloads;
run `omarchy restart shell` if an open panel keeps stale code).

## Connect Interactive Brokers (the "API key")

IBKR's token-based API is the **Flex Web Service**. Set it up once in
[IBKR Client Portal](https://www.interactivebrokers.com/portal):

1. **Create a Flex query** — Performance & Reports → Flex Queries →
   Activity Flex Query → **+**:
   - Name it e.g. `omarchy-positions`.
   - In sections, tick **Open Positions** and select at least:
     *Symbol, Position, Cost Basis, Currency, Description, Open Date/Time*.
   - Set *Level of Detail* to **Lot** — per-lot open dates let the plugin
     show *your* DTD/MTD/YTD (a lot bought mid-period is measured from its
     cost, not the period-start price). With Summary detail the columns
     degrade to plain price returns and the popup shows a warning.
   - Save and note the **Query ID**.
2. **Enable the Flex Web Service** — Performance & Reports → Flex Queries →
   Flex Web Service Configuration (or Settings → Account Settings → Flex Web
   Service): enable it and **generate a token** (valid up to a year).
3. Put both in `~/.config/omarchy/finance/config.json`:

```json
{
  "flex": { "token": "1234567890...", "queryId": "987654" }
}
```

Positions are cached for `positionsCacheHours` (default 8) because Flex
statements are slow to generate; prices refresh every `refreshMinutes`
(default 5) regardless. Middle-click the pill to force a positions refetch.

## Config reference — `~/.config/omarchy/finance/config.json`

```json
{
  "flex": { "token": "", "queryId": "" },
  "baseCurrency": "USD",
  "positionsCacheHours": 8,
  "fxPairs": [["USD", "ILS"], ["CHF", "ILS"], ["EUR", "ILS"]],
  "symbolMap": { "BRK B": "BRK-B" },
  "positions": [
    { "symbol": "AAPL", "quantity": 10, "costBasis": 1900 }
  ]
}
```

- `baseCurrency` — currency the portfolio total is shown in.
- `fxPairs` — the rates row in the popup.
- `symbolMap` — overrides for IBKR symbols whose market-data symbol differs
  (spaces/dots are mapped to `-` automatically).
- `positions` — manual fallback used when no Flex credentials are configured
  (`costBasis` is the total cost for the whole lot, in the stock's currency).
  Once Flex works, this list is ignored — feel free to empty it.

Keep the file private (`chmod 600`); it holds your Flex token.

Widget settings can be added on the bar entry in
`~/.config/omarchy/shell.json`:

```json
{ "id": "idanco.finance", "refreshMinutes": 5,
  "positiveColor": "#81c995", "negativeColor": "#f28b82" }
```

## IPC

```bash
omarchy-shell idanco.finance toggle        # open/close the popup
omarchy-shell idanco.finance detail AAPL   # jump straight to a ticker
omarchy-shell idanco.finance refresh       # force IBKR positions refetch
```

Bind a key in `~/.config/hypr/bindings.lua` if you like, e.g.
`o.bind("SUPER SHIFT, S", "omarchy-shell idanco.finance toggle")`.

## Notes / limitations

- Flex statements reflect positions as of the last generation (typically the
  previous business day) — trades made today appear after the next refetch.
- DTD/MTD/YTD are the returns of your *current open lots* (each lot measured
  from the later of period start and its purchase); realized P&L from shares
  sold during the period and FX moves on baselines are not included.
- The Nasdaq fallback only covers US-listed stocks/ETFs; non-US listings need
  Yahoo (which occasionally rate-limits) or a `symbolMap` entry to a Yahoo
  suffix symbol (e.g. `TEVA` → `TEVA.TA`).
- The AI summary runs the **default Omarchy coding agent** headlessly
  (`omarchy default agent` — claude, codex, opencode, gemini, …) with your
  position, portfolio weights, and recent headlines as context; results are
  cached for 24 hours per ticker (↻ rerun in the panel bypasses the cache).
  It follows whatever agent you set machine-wide, and the header shows the
  agent, model, token counts, and cost (metadata currently reported for
  claude; other agents show just their name).
- The `"ai"` config section can override both without touching the machine
  default: `{ "ai": { "agent": "claude", "model": "claude-haiku-4-5" } }` —
  `model` is passed as `--model` to the agent CLI (claude accepts aliases
  like `haiku`/`sonnet`/`opus` too; crush has no model flag and ignores it),
  and `agent` pins summaries to one agent regardless of `omarchy default
  agent`. Changing either regenerates summaries (the cache is keyed on both).
- Caches live in `~/.cache/omarchy-finance/`; safe to delete anytime.
